# Changelog

## 0.1.4 — 2026-09-27

- Add denser, varied rain streaks with clearer day/night contrast.
- Support an explicit motion setting; retain the device reduced-motion preference when unspecified.

## 0.1.3 — 2026-09-27

- Match the four Free sound icons to Pro: rain, flame, stones and flower.
- Remove the outer border and rounded card frame; support a full-height panel background with fullscreen: true.
- Add equal outer spacing and a rounded 4:3 landscape frame, retaining the 40:60 desktop split and single-column mobile layout.
- Extend layered shoreline land beneath the trees in both day and night scenery.

## 0.1.2 — 2026-09-25

- Give sound controls 40% and scenery 60% of the two-column layout.
- Stack into one column at a card width of 740px, matching Pro and narrow Home Assistant panels.
- Avoid setting the native lang attribute during custom-element construction so Home Assistant can create the card programmatically.

## 0.1.1 — 2026-09-22

- First public GitHub release, with a HACS custom Dashboard repository manifest.
- Install both recordings beside the card and resolve HACS media through Home Assistant's local static endpoint.
- Add HACS and manual installation guides in five languages.
- Keep the four-sound free edition independent of paid features and private infrastructure.

## 0.1.0 — 2026-09-22

- Initial manual-install edition distributed from sulparang.com.
